# 🏗️ DiskCaçamba Guarulhos - Sistema de Locação

Projeto de alta conversão para aluguel de caçambas estacionárias, construído com foco extremo em Performance e SEO Local (Guarulhos).

## 🚀 Tecnologias e Stack
- **Framework:** Astro (SSR Habilitado)
- **Estilização:** Tailwind CSS v4 (Design System focado em Conversão)
- **Hospedagem / Deploy:** Vercel
- **SEO & Markup:** Astro Sitemap + JSON-LD (Schema LocalBusiness)

## 💡 Status do Projeto
✅ **Pronto para Produção (Ready for Deploy)**

O projeto foi submetido a polimento rigoroso, garantindo:
1. **Legibilidade Máxima:** Contraste absoluto.
2. **Escala Controlada:** Tipografia balanceada para Mobile e Desktop.
3. **Menu Indestrutível:** Drawer mobile com trava de scroll nativa.
4. **Velocidade Extrema:** Carregamento focado em nota 100 no PageSpeed.

## 🛠️ Comandos Locais

```bash
# Iniciar servidor local
npm run dev

# Fazer o Build para Produção
npm run build
```

## 📱 Funcionalidades Específicas
- Botão Pulsante do WhatsApp nativo injetado em todas as páginas.
- Gestão de Conteúdo (Blog e Serviços) via *Content Collections*.
- Renderização Dinâmica e estática de alta velocidade.
